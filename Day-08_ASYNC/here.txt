🍔 Mini Challenge: Fast Food Order Flow
📝 Scenario:
You're simulating the process of ordering a burger from a fast-food place.
It involves 3 steps:

Place order – takes 1 second

Cook burger – takes 2 seconds

Serve burger – takes 1.5 seconds

🎯 Your Challenge:
Write three functions using Promises:

placeOrder()

cookBurger(orderMsg)

serveBurger(cookMsg)

Then write an async function startBurgerOrder() that:

Awaits each step

Handles any possible errors using try...catch

Logs the final result

🧠 Tips:
Each function should return a Promise with a setTimeout to simulate delay

Pass messages between functions like we did in the pizza example



🧠 Challenge: Burger & Fries Combo
Goal: Simulate ordering a burger and fries at the same time, then serve both once they’re ready.

🛠️ What to Build
placeOrder() – same as before

cookBurger() – same

fryFries() – NEW function that simulates frying fries

serveCombo() – takes both burger and fries messages and returns a final message

🧪 Hint: Use Promise.all()
This will let you cook the burger and fry the fries at the same time, and wait for both to finish before serving.

🔧 Starter Code (Just Build the 3 New Functions):

function fryFries(orderMsg){
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(`Fries done based on ${orderMsg}`);
    }, 1800);
  });
}

function serveCombo([burgerMsg, friesMsg]){
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve(`🍟🍔 Combo ready:\n${burgerMsg}\n${friesMsg}`);
    }, 1000);
  });
}
Now modify startBurgerOrder() to:

Place the order

Run cookBurger() and fryFries() in parallel using Promise.all

Then call serveCombo()
