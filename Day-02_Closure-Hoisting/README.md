# Day 02 – Closures & Hoisting

## ✅ Concepts Practiced
- Deep closure patterns
- Multiple closures in one function
- Hoisting with function declarations vs expressions
- Temporal Dead Zone (TDZ)

## 🔁 Practice Goals
- Rebuilt closure functions from memory
- Wrote closure-based wallet
- Predicted and confirmed hoisting behaviors

## 🧠 What I Learned
Function declarations are hoisted fully. Function expressions and arrow functions are not. Closures are great for data privacy and managing state across multiple calls.
